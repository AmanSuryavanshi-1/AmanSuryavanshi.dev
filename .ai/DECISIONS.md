# Architectural Decisions (ADR)

1. **Frontend**: Next.js 15 App Router with Tailwind CSS and Radix UI / Shadcn.
2. **Content Management**: Hybrid approach using Sanity CMS for dynamic blogs and Static Data for portfolio elements.
3. **Automation**: Self-hosted n8n workflows integrated with Gemini API.
4. **Rendering**: RSC by default, SSG for blog posts.
5. **Asset Resilience (ADR 5)**: Custom `FallbackImageManager` ensures 100% image load success for all external markdown projects, deliberately overriding default next/image `<Image onError>` for better architectural separation.
6. **Stateless Portfolio (ADR 6)**: The core Next.js portfolio intentionally avoids global state managers (like Redux). *Note: Redux is heavily mentioned in the codebase, but only within static project documentation (e.g., Foodah, AV NewsStream) as strings.*
7. **Centralized Icon Mapping (ADR 7)**: React Icons are globally mapped to string keys inside `src/data/icons/icon-map.ts` to allow dynamic badge rendering without bloating individual components with huge imports.
8. **Domain Cutover & Infrastructure Topology (ADR 8)**: Standardized apex domain `amansuryavanshi.com` on Spaceship Advanced DNS via A-record `76.76.21.21` (due to standard RFC prohibition of apex CNAME without flattening) with `www` permanent 308 redirect to apex via `cname.vercel-dns.com`. Retained dedicated personal Resend sending account (`amansuryavanshi2002`) isolated from client workspaces, with automated DKIM/SPF/DMARC authentication and Resend Forge enabled.
9. **Edge Redirect Harmonization & Historical Route Normalization (ADR 9)**: Consolidated edge redirect layers (`vercel.json`, `next.config.ts`, `src/proxy.ts`) into permanent HTTP 301 redirects to eliminate temporary 307 redirects and preserve search engine link equity during domain cutover. Enforced runtime port-stripping (`rawHost.split(':')[0].toLowerCase()`) in proxy middleware and normalized historical 404 paths (e.g. mapping `/projects/omni-post-ai-technical-documentation` and `/docs/omnipost/01-executive-summary` directly to physical markdown target `/docs/projects/personal/omnipost/02-architecture-and-flow`). Strictly preserved immutable jsDelivr CDN asset filenames (`amansuryavanshi-dev.vercel.app_*.webp`) in static project schemas.
10. **External Syndication Canonicals & Cross-Platform Authority Consolidation (ADR 10)**: Enforced exact canonical URL pointing (`https://amansuryavanshi.com/blogs/<slug>`) across all external publication syndicates (Dev.to and Hashnode) matching Sanity CMS production document updates, preventing duplicate content penalization and concentrating search equity exclusively into the apex domain. Consolidated all public social endpoints (GitHub, Twitter/X, LinkedIn, Reddit, YouTube Studio video descriptions, and channel header links) to `https://amansuryavanshi.com/`. Validated platform constraints: confirmed that solid CTA header buttons on LinkedIn profile intro require LinkedIn Premium, whereas standard profiles display the custom website link as an intro text link (`Portfolio Website`).
